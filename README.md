# weather_app_streamlit
Weather app using Streamlit and OpenWeather API
This is a simple Weather App built using Streamlit and OpenWeatherMap API. The app allows users to check the current temperature and humidity of any city in real-time. It’s beginner-friendly and showcases how to integrate an external API into a Python web app.

Features

Enter the name of any city to get its weather information.

Displays:

🌡️ Temperature (in Celsius)

💧 Humidity

User-friendly interface using Streamlit.
![Weather App Screenshot] (https://github.com/mayuri-ai06/weather_app_streamlit/blob/main/weather%20app.png?raw=true)

How to Use

Clone the repository:

git clone <your-repo-link>


Install required packages:

pip install streamlit requests


Run the app:

streamlit run app.py


Enter your city name in the input box and click Search to view the weather.

Technologies Used

Python

Streamlit (for web interface)

Requests (for API calls)

OpenWeatherMap API (for weather data)
